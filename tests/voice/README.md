# Voice samples for tools/eval-voice.mjs

Record each route with the phone's voice recorder (any format), copy here as `<name>.m4a`, and add `<name>.json`:

```json
{ "lang": "tanglish", "expect": "take the first left, then the first right" }
```

`lang`: tanglish, hinglish, ta, hi, kn, ml, en or auto. `expect`: the route you meant, in plain English.
